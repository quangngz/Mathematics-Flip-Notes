# Mathematics-Flip-Notes

It runs on pushes to main or master, installs with npm ci, builds with:                                               
                                                                                                                        
  npm run build -- --base=/Mathematics-Flip-Notes/                                                                      
                                                                                                                        
  Then uploads dist and deploys it using GitHub’s Pages Actions.                                                        
                                                                                                                        
  Verification passed locally with the same Pages build command.                                                        
                                                                                                                        
  One repo setting may be needed on GitHub: go to Settings → Pages → Build and deployment → Source, and select GitHub   
  Actions.
